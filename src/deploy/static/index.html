Engineering

Our Training Pipeline

From raw field images to accurate, robust disease diagnosis.

1. Data Collection

PlantVillage-style pretrain set (53,599 images / 38 classes) + real-world field fine-tune set (18,354 images / 20 classes, 5 crops)

2. Cleaning & Dedup

SHA256-verified, hash-locked 70/10/10/10 train/calib/val/holdout split with an immutable manifest

3. Advanced Augmentation

CoarseDropout, MixUp, RandAugment, CutMix, brightness/contrast shifts, noise

4. Two‑Stage Training

Pre‑train on PlantVillage-style data (EfficientNetV2-S) → Fine‑tune per species with Class‑Balanced Focal Loss & PEFT

5. Temperature Calibration

Per‑species temperature scaling to improve prediction confidence

6. Leaf Gate & OOD Check

Rejects non-leaf images, wrong species, and out-of-distribution inputs before diagnosis

7. ONNX Export

Models exported to ONNX with dynamic quantization, ready for edge deployment

EfficientNetV2-S Backbone

ImageNet‑1k pretrained, fine‑tuned per species with PEFT on our field dataset

Class‑Balanced Loss

Focal Loss + effective number of samples to handle class imbalance

Field‑Holdout Evaluation

Evaluated by macro-F1 on a locked field holdout, across all 5 crops and 20 diagnostic classes
